# Nexora AI v1

First complete UI prototype for Nexora AI.

## Local run
Install Node.js 18+.
Then:
npm install
npm run dev

Open the local address shown by Next.js.

## Important
This version is a front-end prototype. The buttons do not call real AI services yet.
